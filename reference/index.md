# Package index

## Accessing medRxiv/bioRxiv data

- [`mx_api_content()`](https://docs.ropensci.org/medrxivr/reference/mx_api_content.md)
  : Access medRxiv/bioRxiv data via the Cold Spring Harbour Laboratory
  API
- [`mx_api_doi()`](https://docs.ropensci.org/medrxivr/reference/mx_api_doi.md)
  : Access data on a single medRxiv/bioRxiv record via the Cold Spring
  Harbour Laboratory API
- [`mx_snapshot()`](https://docs.ropensci.org/medrxivr/reference/mx_snapshot.md)
  : Access a static snapshot of the medRxiv repository

## Performing the search

- [`mx_reporter()`](https://docs.ropensci.org/medrxivr/reference/mx_reporter.md)
  : Search and print output for individual search items
- [`mx_search()`](https://docs.ropensci.org/medrxivr/reference/mx_search.md)
  : Search preprint data
- [`print_full_results()`](https://docs.ropensci.org/medrxivr/reference/print_full_results.md)
  : Search for terms in the dataset
- [`run_search()`](https://docs.ropensci.org/medrxivr/reference/run_search.md)
  : Search for terms in the dataset

## Helper functions

- [`mx_caps()`](https://docs.ropensci.org/medrxivr/reference/mx_caps.md)
  : Search term wrapper that allows for different capitalization of term
- [`mx_crosscheck()`](https://docs.ropensci.org/medrxivr/reference/mx_crosscheck.md)
  : Check how up-to-date the maintained medRxiv snapshot is
- [`mx_download()`](https://docs.ropensci.org/medrxivr/reference/mx_download.md)
  : Download PDF's of preprints returned by a search
- [`mx_export()`](https://docs.ropensci.org/medrxivr/reference/mx_export.md)
  : Export references for preprints returning by a search to a .bib file
