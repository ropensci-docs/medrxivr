# Search for terms in the dataset

Search for terms in the dataset

## Usage

``` r
print_full_results(num_results, deduplicate)
```

## Arguments

- num_results:

  number of searched terms returned

- deduplicate:

  Logical. Only return the most recent version of a record. Default is
  TRUE.
